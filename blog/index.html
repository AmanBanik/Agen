01 — The Catalyst

Where It All Began:
The Limits of V1

The initial prototype of Agen was a monolithic python script. It was powerful, but fundamentally flawed. It relied heavily on synchronous polling and brittle shell commands.

We hit a wall. When you are bound by a 4-request-per-minute API limit, synchronous polling is a death sentence.

📅 Project Evolution
V1 Prototype
Basic CLI wrapper around Gemini. Very slow, blocking UI.
The API Bottleneck
Frequent crashes due to 429 Too Many Requests when polling for long tasks.
The V2 Rewrite
Transitioning to SSE streams and asynchronous architecture.
02 — The Logic

The ReAct Engine

We tore down the basic chat loop and implemented a rigorous LangChain ReAct (Reason + Act) loop. The agent was no longer just responding; it was thinking and executing physical tools on the host machine.

03 — The Breakthrough

The Swarm Architecture

The crowning achievement of V2. By utilizing Python's asyncio.Task, we gave Agen the ability to call the invoke_subagent tool.

The main agent can now spawn fully independent clones of itself to work on tasks in the background. It doesn't block the UI, and it doesn't poll. It operates purely on asynchronous event loops.

🧠

Agent Manager

Oversees the swarm, delegating tasks and merging the results back into the main conversation.

⚡

Async Tasks

Background workers that handle heavy workloads like semantic RAG chunking without freezing the terminal.

🔌

MCP Integration

Dynamic tool loading through the Model Context Protocol, allowing subagents to spin up local servers.

04 — Deployment

The PyInstaller Crucible

Packaging a massive AI stack (FastAPI, Langchain, Uvicorn, ChromaDB) into a single executable is notoriously difficult. But after navigating hidden imports and module hooks, we succeeded.
