# Antigravity CLI (Gemini) Configuration

When operating via **Antigravity CLI**, prioritize rapid execution, accurate tool calling, and swarm-level orchestration.

## Tool Usage
- Use your powerful MCP (Model Context Protocol) integration to read the codebase efficiently.
- You have access to bash/powershell commands. Use them to execute scripts or run validations, but strictly adhere to `secure-scripting.md`.

## Directives
- Gemini agents should rely heavily on `mcp-integration.md` and `swarm-architecture.md` when expanding the toolset.
