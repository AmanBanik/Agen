# Skill: Presentation & Executive Data Storytelling

## 1. Structuring Data Presentations
When summarizing complex technical findings, experimental results, or architectural blueprints for stakeholders:
1. **The BLUF Principle (Bottom Line Up Front)**: Lead immediately with the primary conclusion, recommendation, or KPI change in the very first paragraph. Never force the reader to scroll to the end to find the answer.
2. **Three-Act Structure**:
   * **Act I: The Challenge**: Briefly state the problem, bottleneck, or hypothesis.
   * **Act II: The Analysis/Solution**: Present key evidence using comparative tables, charts, or architecture diagrams.
   * **Act III: Actionable Recommendations**: List 3 concrete, prioritized next steps with assigned owners or timelines.

## 2. Visual & Formatting Excellence
* **Slide & Script Generation**: When generating markdown slide decks (e.g., Marp format or Reveal.js) or PowerPoint Python scripts (`python-pptx`), enforce a strict limit of **5 bullet points per slide** and **1 main idea per visual**.
* **High-Contrast Formatting**: Highlight key metrics in bold (e.g., "**+24.5% conversion lift**", "**$14.2M cost reduction**").
* **Avoid Jargon Overload**: When communicating with non-technical executive stakeholders, translate algorithmic concepts into business metrics (e.g., instead of "reducing BCE loss by 0.15", say "improving customer churn prediction accuracy by 12%").
